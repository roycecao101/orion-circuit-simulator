Orion Circuit Simulator

Orion is an interactive web-based circuit simulator designed to demonstrate basic DC circuit concepts in a space-station themed interface. It models a series circuit with a power source, internal resistance, wire resistance, and three subsystem loads.

Features
Adjustable source voltage and resistance values
Real-time current, voltage, and power calculations
Battery and wire power loss visualization
Circuit efficiency calculation
Interactive main breaker
Animated electron flow
Status indicators for life support, communications, and engine systems
Technologies
HTML
CSS
JavaScript
SVG
Running the Project

Open index.html in a web browser, or run:

open index.html

No external libraries or installation are required.
